SMART STUDENT STUDY PLANNER
    
        ABOUT THE PROJECT
        The Smart Student Study Planner is a Python application designed to  help students organize their study tasks and track  their progress.

        FEATURES
        .Add new study tasks
        .View all saved tasks
        .Mark tasks as completed
        .check study progress
        .Delete tasks
        .Save tasks and exit the application

        TECHNOLOGIES USED
        .Python
        .Functions
        .List and dictionaries
        .File handling

        HOW TO RUN
        1.Install python on your computer.
        2.Download or clone this repository.
        3.Open the project folder in VS code.
        4.Open the terminal in the project folder.
        5.Run the following command:

        python app.py
